# Лабораторная работа №5: Строки, векторы и словари

## Автор

## Вариант

## Цель
Научиться обрабатывать текст с помощью строк, хранить последовательности в векторе и находить данные по ключу в словаре, а затем объединить эти конструкции в обработке списка записей.

## Описание
Программа состоит из четырёх частей. Первой строкой вводится буква части, затем программа читает только вход выбранной части.

| Часть | Конструкция | Задача |
| :-: | :-- | :-- |
| A | `string` | Преобразовать латинские буквы строки в нижний регистр |
| B | `vector<int>` | Вывести элементы в обратном порядке |
| C | `map<string, int>` | Прибавить приращение к значению ключа (отсутствующий ключ сначала получает 0) и вывести словарь |
| D | `vector<map<string, string>>` | Вывести имена владельцев записей с неверным адресом почты |

В части D адрес считается верным, если в нём ровно один символ `@`, перед ним и после него есть хотя бы один символ и в адресе нет пробелов.

## Входные данные
- **A:** одна строка ASCII длиной до 200 символов.
- **B:** `n` от 0 до 100, затем `n` целых чисел от -1000 до 1000.
- **C:** число пар от 0 до 100, затем пары `ключ число` по одной на строке, затем ключ запроса и приращение. Ключ — слово ASCII до 40 символов без пробелов, числа от -1000 до 1000.
- **D:** число записей от 0 до 100, затем для каждой записи две строки: `name` и `email`. Поле — от 1 до 200 символов ASCII без пробелов по краям.

## Выходные данные
- **A:** преобразованная строка.
- **B:** элементы через пробел в обратном порядке.
- **C:** пары `ключ число` по одной на строке в порядке ключей.
- **D:** имена владельцев неверных адресов по одной на строке, в исходном порядке.

Пустой результат обозначается `EMPTY`, неверный ввод — `INVALID`.

## Тесты
| Часть | Ввод | Ожидаемый результат |
| :-: | :-- | :-- |
| A | `" Cat a12 dog Cat "` | `" cat a12 dog cat "` |
| A | пустая строка | `EMPTY` |
| A | `123 !?` | `123 !?` |
| B | `7` / `-2 0 3 3 -1 4 0` | `0 4 -1 3 3 0 -2` |
| B | `1` / `5` | `5` |
| B | `0` | `EMPTY` |
| B | `2` / `5 1001` | `INVALID` |
| C | `4` / `beta 2` / `alpha 5` / `beta 3` / `gamma -1` / `beta 4` | `alpha 5` / `beta 7` / `gamma -1` |
| C | `1` / `alpha 5` / `delta -3` | `alpha 5` / `delta -3` |
| C | `0` / `zeta 7` | `zeta 7` |
| C | `0` / `zeta 1001` | `INVALID` |
| D | `4` / `Anna` / `anna@example.org` / `Boris` / `boris.example.org` / `Chris` / `@example.org` / `Dana` / `d@x@y` | `Boris` / `Chris` / `Dana` |
| D | `0` | `EMPTY` |
| D | `2` / `Eve` / `eve@` / `Fay` / `f ay@x.org` | `Eve` / `Fay` |
| D | `2` / `Anna` / `a@b` / пустая строка / `x@y` | `INVALID` |
| — | `E` | `INVALID` |

## Пример запуска
```

Boris

Chris
@example.org
Dana

```

Вывод:
```
Boris
Chris
Dana
```
